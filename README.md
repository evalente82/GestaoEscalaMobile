API - Gestão de Escalas e Permutas
📖 Sobre o Projeto
Este repositório contém a API RESTful para o sistema de Gestão de Escalas e Permutas. Desenvolvido em C# com ASP.NET Core 7, este back-end é responsável por toda a lógica de negócio, gerenciamento de dados e autenticação da plataforma.

A aplicação foi projetada para ser o núcleo de um ecossistema que permite a funcionários visualizarem suas escalas de trabalho e solicitarem trocas (permutas) entre si de forma organizada.

Este projeto serve como back-end para a aplicação mobile:

📱 GestaoEscalaMobile

✨ Funcionalidades Principais
Gestão de Usuários: CRUD completo para os usuários do sistema.

Gestão de Escalas: Criação e gerenciamento das escalas de trabalho.

Gestão de Permutas: Lógica para solicitação, aprovação e recusa de trocas de escala.

Arquitetura RESTful: Endpoints bem definidos para cada recurso da aplicação.

Documentação de API: Geração automática de documentação com Swagger (OpenAPI) para fácil visualização e teste dos endpoints.

🚀 Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:

C#

.NET 7

ASP.NET Core Web API

Entity Framework Core 7: ORM para comunicação com o banco de dados.

SQL Server: Banco de dados relacional.

Swagger (Swashbuckle): Para documentação da API.
